# 5분 경제분석 카드뉴스 이미지 출처

모든 이미지는 생성형 이미지 도구로 만들었고, `../cards.plan.json`의 카드별 프롬프트와 보강 프롬프트를 기준으로 추출했다. 생성형 이미지이므로 실제 기관, 실제 문서, 실제 거래 화면을 재현한 것이 아니다.

| 파일 | 장면 | 사용 카드 |
|---|---|---|
| scene-01-cover-hook.webp | 경제뉴스를 내려놓고 핵심 지표만 보는 책상 | 표지 |
| scene-02-narrative-turn.webp | 돈이 먼저 움직이는 세 가격표를 상징하는 분석 책상 | 돈의 움직임 |
| scene-03-narrative-turn.webp | 금리와 빌리는 값을 상징하는 대출·채권 문서 | 금리 |
| scene-04-narrative-turn.webp | 원화와 달러가 비교되는 환율 장면 | 환율 |
| scene-05-narrative-turn.webp | 유가와 비용 부담을 상징하는 석유 저장 시설 | 기름값 |
| scene-06-narrative-turn.webp | 숫자 하나만 확대해 보는 위험 | 숫자 함정 |
| scene-07-narrative-turn.webp | 세 가격표가 같은 방향을 가리키는 장면 | 같은 방향 |
| scene-08-narrative-turn.webp | 항만 수출과 기업 차입 부담을 함께 보는 장면 | 수출과 돈값 |
| scene-09-closing-checkpoint.webp | 다섯 신호를 모아 마지막으로 확인하는 책상 | 확인 |
