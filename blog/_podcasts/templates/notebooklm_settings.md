# NotebookLM 고정 설정 (에피소드마다 동일하게)

우리 파이프라인은 오디오를 만들지 않는다. `script.md`(완결 산문 소스 문서)를 NotebookLM 에 넣어
오디오 개요(Audio Overview)를 생성한다. 매 에피소드 아래 설정을 그대로 쓴다.

## 1. 소스 등록
- 새 노트북 생성 후, 그 에피소드의 `script.md` 하나만 소스로 업로드한다.
- 다른 소스(웹·PDF)를 섞지 않는다. 문서 하나로 완결되게 이미 기획했으므로, 소스를 섞으면
  근거가 흐려지고 문서 밖 사실이 새어든다.

## 2. 출력 언어
- Audio Overview 언어를 한국어로 설정한다(설정에서 출력 언어 Korean).

## 3. Customize(맞춤 지시) 상자에 붙여넣기
```
이 소스 문서 하나만 근거로 삼아 진행하세요. 문서에 없는 사실이나 숫자는 만들지 마세요.
처음 듣는 사람도 따라오게 쉬운 한국어로, 소리 내어 자연스러운 말투로 대담하세요.
모든 숫자는 분모와 기간을 함께 말해 귀로만 들어도 이해되게 하세요.
투자 권유나 목표가, 매수매도 판단, 확정 전망은 하지 마세요. 교육용 설명입니다.
오프닝에서 던진 질문을 마지막에 판단으로 갚고, 다음에 확인할 지표로 닫으세요.
```

## 4. 길이·톤
- 소스가 900~1500단어면 대략 8~15분 분량이 나온다.
- 톤: 두 진행자의 편안한 대담. 우리는 대본(2인 배분)을 쓰지 않는다. NotebookLM 이 배분한다.

## 5. 내려받기 후
- 생성된 오디오를 `.m4a` 로 내려받는다(파일명 자유).
- 그 에피소드 `episode.yaml` 의 `status` 를 `ready` 로 바꾼다.
- 발행: `uv run python -X utf8 blog/_podcasts/_lib/publish_podcast.py --episode <id> --audio <m4a 경로>`
