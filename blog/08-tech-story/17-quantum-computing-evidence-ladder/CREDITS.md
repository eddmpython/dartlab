# CREDITS

이 글의 로컬 `assets/`는 발행 전 검수용 staging이다. durable 원본과 웹 서빙 정본은 기존 Hugging Face 미디어 저장소 `eddmpython/dartlab-media`의 콘텐츠 해시 객체이며, 경로, 역할, SHA-256 대응은 `media/catalog.json` 한 곳에서 관리한다.

## 래스터 이미지

모든 래스터는 내장 이미지 생성 모드로 신규 생성했다. 특정 회사 장비, 실제 연구실, 제어 화면을 재현하지 않은 설명용 개념 장면이다.

| assetKey | 수급 방식 | 최종 프롬프트 핵심 | 사실성 경계 |
|---|---|---|---|
| `17-hero` | 내장 이미지 생성 신규 | 16:9 다크 네이비 연구시설에 금빛 초전도 희석냉동기, 분리된 이온트랩 광학 테이블, 배경 HPC 센터를 배치하고 서로 다른 방식이 한 기계처럼 합쳐 보이지 않게 구성 | 특정 회사 냉동기, 이온트랩, 데이터센터와 실제 연결 방식을 복제하지 않은 산업 스택 개념 이미지 |
| `17-logical-qubit` | 내장 이미지 생성 신규 | 16:9 극저온 챔버의 물리 제어 노드 격자 가운데 여러 노드가 amber 논리 영역을 보호하고 cyan 잡음과 red 오류 신호를 감지하는 장면 | 실제 표면부호 배선, 큐비트 구조, 오류 신드롬 측정 회로를 재현하지 않은 오류정정 개념 이미지 |
| `17-quantum-security` | 내장 이미지 생성 신규 | 16:9 데이터센터 보안 업그레이드 장면에서 기존 네트워크의 amber PQC 경로와 선택된 광링크의 cyan QKD 경로를 분리 | 실제 고객망, 상용 보안장비, QKD 토폴로지를 복제하지 않은 보안 전환 개념 이미지 |

최종 프롬프트에는 브랜드, 로고, 읽을 수 있는 문자와 숫자, 식별 인물, 가짜 공식 화면, 자물쇠 상징, 판타지 양자 효과, 워터마크를 제외하도록 명시했다. `17-hero`는 초전도와 이온트랩 구역을 분리했고, `17-quantum-security`는 PQC와 QKD가 하나의 기술처럼 합쳐 보이지 않게 두 경로를 분리했다.

## SVG 도해

아래 도해는 저장소 안에서 직접 작성한 설명용 벡터 자산이다. 공통 배경은 `#0a0e1a`, 핵심 강조는 amber `#fbbf24`, 보조는 cyan `#22d3ee`, 위험과 반증은 red `#fb7185`를 사용했다.

- `17-quantum-computation-flow`: 준비, 중첩, 얽힘, 간섭, 반복 측정의 계산 순서를 보여 준다.
- `17-physical-logical-qubit`: 물리 오류율이 임계값 위와 아래일 때 코드 거리와 논리 오류의 방향이 어떻게 달라지는지 보여 준다.
- `17-modality-map`: 초전도, 이온트랩, 중성원자, 광자, 어닐링의 강점과 병목을 비교한다.
- `17-quantum-stack`: QPU, 환경과 제조, 제어와 판독, 오류정정, HPC, 응용의 층을 연결한다.
- `17-evidence-ladder`: 원리 발표에서 외부 접근, 주문, 설치, 매출, 반복 주문과 현금까지의 증거 단계를 나눈다.
- `17-company-network`: 직접 하드웨어, 제조와 제어, 클라우드, 보안 층의 상장사와 공시 범위를 배치한다.
- `17-pqc-qkd`: 기존 네트워크에서 실행되는 PQC와 선택된 광링크가 필요한 QKD, QRNG의 경계를 비교한다.
- `17-scenario-map`: 제조지원, 반복 주문, 논리 연산, PQC 전환의 조건, 지표와 무효화 조건을 비교한다.

도해의 숫자와 회사 배치는 본문과 `brief.json.evidenceMap`의 공식 원문 및 범위 주석을 따른다. 회사 로고, 실제 제품 UI, 식별 가능한 인물은 사용하지 않았다.
