# CREDITS

이 글의 로컬 `assets/`는 발행 전 검수용 staging이다. durable 원본과 웹 서빙 정본은 기존 Hugging Face 미디어 저장소 `eddmpython/dartlab-media`의 콘텐츠 해시 객체이며, 경로, 역할, SHA-256 대응은 `media/catalog.json` 한 곳에서 관리한다.

## 래스터 이미지

모든 래스터는 내장 이미지 생성 모드로 신규 생성했다. 특정 회사 제품, 실제 파일럿 라인, 시험기관이나 옥외 시험장을 재현하지 않은 설명용 개념 장면이다.

| assetKey | 수급 방식 | 최종 프롬프트 핵심 | 사실성 경계 |
|---|---|---|---|
| `18-hero` | 내장 이미지 생성 신규 | 16:9 태양광 발전소와 엔지니어, 전경에 amber-violet 상부막과 blue silicon 하부 셀의 절개 모듈을 배치 | 특정 회사 모듈이나 실제 발전소를 복제하지 않은 탠덤 산업 개념 이미지 |
| `18-spectrum-cutaway` | 내장 이미지 생성 신규 | 16:9 유리, 얇은 amber-violet 페로브스카이트, 재결합층, 피라미드형 실리콘과 빛 분할을 사실적인 단면으로 구성 | 실제 상용 셀의 층 두께, 조성, 전극과 제조사 구조를 재현하지 않은 원리 설명 이미지 |
| `18-coating-line` | 내장 이미지 생성 신규 | 16:9 클린룸 시트 투 시트 파일럿 생산, 산업 웨이퍼, 코팅 헤드, 계측 장비와 미세한 상부막을 구성 | Qcells, Oxford PV, LONGi 등 특정 회사 라인과 실제 장비 배치를 복제하지 않은 공정 개념 이미지 |
| `18-stress-test` | 내장 이미지 생성 신규 | 16:9 환경 신뢰성 챔버 안의 대면적 모듈, 응결, 열원, 자외선 광원, 전기 부하 케이블과 관찰 엔지니어를 구성 | 실제 IEC 시험 순서, TÜV 또는 Qcells 시험실과 특정 인증 결과를 재현하지 않은 가속시험 개념 이미지 |
| `18-field-validation` | 내장 이미지 생성 신규 | 16:9 해안과 사막 환경이 만나는 옥외 시험대, 여러 크기의 모듈, 기상 관측기와 현장 엔지니어를 구성 | PACT, NREL, DOE 또는 특정 기업의 실제 시험장과 성능 데이터를 재현하지 않은 모집단 검증 개념 이미지 |

최종 프롬프트에는 브랜드, 로고, 읽을 수 있는 문자와 숫자, 인증 마크, 가짜 공식 화면과 워터마크를 제외하도록 명시했다. 모든 장면은 기술 원리와 검증 공간을 설명하며 실제 회사의 성능 증거로 사용하지 않는다.

## SVG 도해

아래 도해는 저장소 안에서 직접 작성한 설명용 벡터 자산이다. 공통 배경은 `#0a0e1a`, 핵심 강조는 amber `#fbbf24`, 보조는 cyan `#22d3ee`, 위험과 반증은 red `#fb7185`를 사용했다.

- `18-evidence-distribution`: 기록 셀에서 대면적 분포, 모듈, 스트레스, 옥외 모집단, 반복 사업까지 같은 제품으로 이어져야 하는 증거 단계를 보여 준다.
- `18-spectrum-split`: 단일 실리콘의 초과 에너지·미흡수 손실과 탠덤의 파장 분담을 비교한다.
- `18-2t-4t`: 직렬 전류맞춤이 필요한 2단자와 독립 운전 대신 부품과 배선이 늘어나는 4단자를 비교한다.
- `18-scale-gap`: 1㎠급 기록 셀에서 산업 웨이퍼, 산업 형식 모듈로 갈 때 새로 생기는 분모와 공장 지표를 보여 준다.
- `18-degradation-map`: 빛, 열, 수분, 전압과 음영이 상분리, 이온 이동, 계면 반응과 역바이어스를 거쳐 출력과 보증에 영향을 주는 경로를 연결한다.
- `18-lead-loop`: 정상 봉지, 파손 누출 억제, 회수 물류와 재료 재사용을 생산자 책임의 고리로 연결한다.
- `18-company-map`: LONGi, Qcells, Oxford PV, JinkoSolar와 First Solar의 직접 공개 증거와 공개 결손을 분리한다.
- `18-financial-traces`: 한화솔루션, First Solar, JinkoSolar의 회사 전체 재무와 탠덤 전용 손익의 공개 결손을 구분한다.
- `18-scenario-map`: 대면적 효율 분포, 옥외 열화, 실리콘 가격과 납 회수의 조건, 결과와 반증 신호를 비교한다.

도해의 수치와 회사 배치는 본문과 `brief.json.evidenceMap`의 공식 원문 및 범위 주석을 따른다. 효율 기록, 시험, 첫 출하와 회사 전체 재무를 한 제품의 성과나 탠덤 전용 손익으로 합산하지 않았다.
