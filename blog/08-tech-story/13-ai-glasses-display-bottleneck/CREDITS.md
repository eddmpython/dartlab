# CREDITS

이 글의 로컬 `assets/`는 발행 전 검수용 staging이다. durable 원본과 웹 서빙 정본은 기존 Hugging Face 미디어 저장소 `eddmpython/dartlab-media`의 콘텐츠 해시 객체이며, 경로·역할·SHA-256 대응은 `media/catalog.json` 한 곳에서 관리한다.

## 래스터 이미지

| assetKey | 수급 방식 | 설명·프롬프트 요약 | 사실성 경계 |
|---|---|---|---|
| `13-hero` | 기존 image generation 자산 재사용 | 렌즈 한쪽에 짧은 정보가 켜진 일반형 AI 안경의 어두운 편집 이미지 | 특정 회사·제품을 재현하지 않은 개념 장면 |
| `13-three-stages` | `image_gen` 신규 생성 | 화면 없는 카메라·오디오형, 짧게 보는 단안 화면형, 공간형 AR을 왼쪽에서 오른쪽으로 비교하는 무로고 16:9 편집 이미지 | 실제 출시 제품이 아니라 세 제품 단계의 차이를 설명하는 개념 장면 |
| `13-system-budget` | `image_gen` 신규 생성 | 배터리·프로세서·카메라·스피커·열 분산·처방 렌즈·휴대폰 연결을 한 안경 분해도에 배치한 무로고 16:9 편집 이미지 | 내부 부품 위치와 크기는 특정 제품의 분해 결과가 아닌 시스템 제약 설명용 구성 |
| `13-microled-wafer` | 기존 생성 자산 재사용 | 현미경 아래 마이크로LED 마이크로디스플레이 웨이퍼의 기술 편집 이미지 | 특정 제조사 웨이퍼나 실제 수율을 재현하지 않은 개념 장면 |
| `13-display-cleanroom` | 기존 생성 자산 재사용 | 정밀 디스플레이 생산·검사 클린룸의 기술 편집 이미지 | 특정 회사 공장·장비가 아닌 제조 층위 설명용 개념 장면 |

신규 생성 자산은 내장 `image_gen` 모드를 사용했다. 프롬프트에는 무로고·무브랜드·무문자·무워터마크, 현실적인 착용 크기, 다크 그래파이트 배경, cyan 데이터 흐름과 amber 열 표현을 명시했다. 생성 결과를 WebP로 변환한 뒤 원본 해상도로 눈검수했다.

## SVG 도해

아래 도해는 저장소 안에서 직접 작성한 설명용 벡터 자산이다. 공통 캔버스는 1200×675, 배경은 `#0a0e1a`, 핵심 강조는 amber `#fbbf24`와 cyan `#22d3ee`를 사용했다.

- `13-maturity-ladder`: 화면 없는 카메라·오디오형, 짧은 화면형, 공간형 AR의 성숙도와 시스템 난도.
- `13-constraint-budget`: 새 기능이 전력·열·공간·무게·사회적 신뢰 예산을 함께 쓰는 관계.
- `13-optical-path`: 마이크로디스플레이의 빛이 도파관과 아이박스를 지나 눈에 도착하는 경로. 0.9%→3.1% 표기는 *Applied Optics* 2024 특정 연구 설계 사례이며 상용 일반값이 아니다.
- `13-interaction-stack`: 음성·안경다리 터치·근전도 손목 밴드·카메라 제스처의 편의와 비용.
- `13-business-evidence`: EssilorLuxottica 2025 판매·그룹 마진과 Meta Reality Labs 2026년 1분기 세그먼트 수치의 서로 다른 범위.
- `13-future-scorecard`: 작업 완결성·하루 착용·처방 유통·자연스러운 입력·주변 신뢰의 다섯 관찰 축.

도해의 숫자 출처와 범위 한계는 본문 검증표 및 `brief.json.evidenceMap`에 함께 기록했다. 회사 로고, 제품 UI, 식별 가능한 인물은 사용하지 않았다.
