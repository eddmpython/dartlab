# Agent Runtime

DartLab은 모델 계정이나 API 키를 대신 보관하지 않는다. 사용자가 이미 로그인해 사용하는 설치형 에이전트 CLI를 발견하고, 그 세션에 DartLab의 읽기 전용 분석 도구를 연결한다.

## 사용자 여정

1. Runtime Center가 Codex, Claude Code, Cline의 설치 상태를 확인한다.
2. 설치되지 않은 런타임에는 검토 가능한 공식 설치 계획을 보여 준다.
3. 설치된 런타임은 로그인 상태와 DartLab MCP 연결을 각각 확인한다.
4. 사용자는 준비가 끝난 런타임을 새 대화의 기본값으로 고른다.
5. 대화가 시작되면 그 런타임은 대화가 끝날 때까지 고정된다.
6. Ask는 에이전트의 진행, 도구 호출, 답변, 근거, 품질 상태를 같은 스트림으로 보여 준다.

런타임이 하나만 준비되면 자동 선택할 수 있다. 둘 이상 준비됐고 기본값이 없으면 임의 선택하지 않고 Runtime Center 선택을 요구한다.

## 답변 채택 조건

정량 질문은 대상, 지표, 기간의 claim cell이 모두 정확한 값 근거로 덮여야 한다. 문서 질문은 요구된 문서 근거가 있어야 한다. 근거가 부족한 첫 답변은 같은 네이티브 세션에서 한 번 자동 보완한다. 보완 뒤에도 기준을 통과하지 못하면 답변과 수집 근거를 최종 근거로 채택하지 않는다.

최종 채택 근거와 후보 근거는 UI에서 구분한다. 후보 근거를 여는 행동은 조회일 뿐 검증 완료로 기록되지 않는다. 사용자가 exact evidence를 확인해야 product outcome이 검증 상태로 전이된다.

## 현재 지원 범위

Codex와 Claude Code는 설치, 로그인, DartLab MCP 연결이 모두 확인되면 사용할 수 있다. Cline은 현재 ACP 세션이 DartLab MCP 도구를 노출하지 않으므로 준비 완료로 표시하지 않고 다른 런타임 선택을 안내한다.
