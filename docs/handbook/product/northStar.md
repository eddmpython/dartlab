# 북극성

DartLab의 북극성은 `weeklyVerifiedAnalysisLoops`다. 실제 기업, 시장, 공시 질문이 정식 엔진 계산과 출처를 거쳐 답변이 되고, 사용자가 exact evidence 또는 artifact를 직접 확인했을 때만 한 건으로 센다.

모델 응답 수, 도구 호출 수, 페이지뷰, 테스트 통과 수는 북극성 분자가 아니다. 권위 있는 주간 cohort가 없으면 값은 `미측정`으로 둔다.

## 제품 성숙도 축

성숙도는 근거, 커버리지, 검증강도, 직관성, 속도, 효율성, 안정성, 혁신성을 독립적으로 본다. 기능 코드가 있다는 사실만으로 점수를 올리지 않는다. 실제 공개 표면의 반복 여정과 실패 가능한 실행 가드가 추가되거나 사라졌을 때 outcome review에서 재판정한다.

## 완료 판정

완료된 제품 루프는 다음 조건을 모두 만족한다.

- 실제 사용자 질문이나 작업에서 시작한다.
- 정식 DartLab 계약을 호출한다.
- 결과가 출처 identity와 기준 시점을 보존한다.
- 사용자가 exact evidence를 열어 확인할 수 있다.
- 실패, 취소, 재연결이 세션과 결과 원장을 손상시키지 않는다.

하나라도 충족하지 못하면 구현은 존재해도 검증 완료 루프로 세지 않는다.
