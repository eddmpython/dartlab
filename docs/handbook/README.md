# DartLab handbook

이 폴더는 DartLab의 현재 동작과 깨지면 안 되는 계약의 영구 정본이다.

- [product](product/README.md): 사용자가 지금 할 수 있는 것과 아직 할 수 없는 것
- [architecture](architecture/README.md): 계층, 데이터, 런타임, 신뢰 경계
- [reference](reference/README.md): 정확한 공개 계약과 상태 표
- [operations](operations/README.md): 개발, 검증, 배포, 복구 절차

열거 가능한 사실은 코드가 정본이며 handbook은 그 투영이다. 구현 수, 파일 수, capability 수처럼 자동으로 변하는 숫자를 손으로 고정하지 않는다. 정확한 목록은 생성 계약이나 실행 가능한 audit가 대조한다.

임시 구현 설계와 진행률은 handbook에 두지 않는다. 완료 시 코드 실물에서 현재 계약을 다시 추출해 이 handbook에 반영한다.
