## 지금까지 작동하는 것 (성과)

- **IPO 자동 판별**: `report_nm 첫 괄호 "지분증권" + corp_cls="E" + 빈 stock_code` 3조건. 6개월 corp_cls=E
  증권신고서 826건 중 783건(펀드·채권·유동화)을 자동 배제, 지분증권 43건 오분류 0.
- **6카테고리 추출**: 공모개요·공모일정·밸류에이션(적용 PER·할인율)·재무3개년·공모 배정·리스크. dart4.xsd
  `<TITLE>` 구조 앵커링(텍스트 변형 정규식 누적이 아니라 구조 기준)이라 발행사 변형에 강건.
- **원문 자체 항등식 자기검증**: 추출값을 원문의 관계식으로 자기검증 — 공모가×주식수=모집총액 /
  비교PER×주당순익÷주식수=주당평가액 / 주당평가액×(1−할인율)=공모가밴드 / 자산=부채+자본. 발행사 원문의
  콤마 오타도 항등식이 검출·복구. 항등식 미통과 값은 명시 플래그로 표기해 **틀린 값을 맞다고 내놓지 않음**.
- **라이브 동작**: 최근 윈도우에서 발행사를 자동 발굴해 본문을 직독, 캐시에 없던 발행사도 항등식이 검증됨
  (사람 라벨 0). 원문근거 = 접수번호(rcept)로 DART 원문에 바로 연결.

```python
from dartlab.providers.dart.securitiesRegistration import classifyIpo, parseIpoProspectus
import dartlab

classifyIpo("증권신고서(지분증권)", "E", "", "주식회사 기도산업")  # → {'isIpo': True, 'subtype': '지분증권', ...}
r = parseIpoProspectus(content)   # offering / valuation / financials / allocation / risk / identities
df = dartlab.scan("ipo")          # 최근 신규상장 발굴 + 핵심값 횡단
```

## 점검 중

- **파싱 견고성**: 발행사를 더 교차해 양식 변종(열 수 변동·병합 셀·콤마 오타)에서의 정확도를 계속 실측 중.
  견고성은 소수 바스켓이 아니라 유니버스 규모에서 증명한다는 원칙으로 보고 있습니다.
- **소비 레이어**: 현재는 API/터미널에서 직독하는 형태입니다. 사람이 읽기 좋은 리포트 뷰는 별도 리포트 엔진
  위에 얹는 후속 작업으로 진행 중입니다.

## 남은 막힌 지점 (정직 공유)

- **유통가능물량·보호예수 워터폴(카테고리 일부)**: 상장후 유통가능물량과 보호예수는 별 하위표 구조라 추가
  파싱 트랙으로 분리. 현재 6카테고리 중 이 세부는 미완.
- **확정공모가·수요예측 결과**: 이는 증권신고서 본문이 아니라 *사후공시*(증권발행조건확정) 트랙입니다. 본
  추출은 FULL 신고서(초판·기재정정) 대상이고, 확정가·경쟁률·의무보유확약은 별도 후속 트랙으로 둡니다.
- **공개 범위**: 공모개요·공모일정 같은 메타는 공개 후보지만, 밸류·리스크(본문성)는 원문 인용 성격이라
  공개 게시가 아니라 터미널 직독 형태로 다룹니다. 무엇을 어디까지 공개로 노출할지 선을 검토 중입니다.
- **고저평가 단정 회피**: 적용 PER·할인율은 발행사가 *선택한* 비교군 기준이라 "고/저평가" 단정 대신 비교
  좌표로만 제시합니다(투자판단 단정 회피).
