# 기술별 조사 원장 (Tech Ledger)

> 목적: 같은 기술을 반복 재조사하지 않기 위해, 기술 하나당 파일 하나로 "마지막 조사일 / 카테고리별로 뭘 봤나 / 본 자료 / 채택 결정"을 누적 기록한다.
> 상위 문서: `innovation-stack-research/00~04` (2026-06-17 시점의 전체 thesis 스냅샷). 본 폴더는 그 위에 얹는 **살아있는 기술별 원장**이다. 스냅샷이 낡아도 여기 개별 파일은 조사할 때마다 갱신한다.

## 이 원장을 쓰는 법

1. 어떤 기술을 조사하기 전에 먼저 해당 파일(`tech/<이름>.md`)이 있는지 본다. 있으면 "마지막 조사일"과 "현재 결정"부터 읽는다.
2. 이미 결론 난 항목이면 재조사하지 말고, 결론이 바뀔 새 근거(새 메이저 버전, 병목 실측, 정책 변경)가 있을 때만 새 조사 블록을 append 한다.
3. 조사했으면 그 파일의 "조사 이력"에 날짜 블록을 하나 추가한다. 카테고리별 관찰 + 본 자료(URL) + 결정을 반드시 남긴다.
4. 결정이 바뀌면 파일 상단 "현재 결정" 한 줄을 갱신하고, 아래 이력에는 옛 결정을 남겨둔다(왜 바뀌었는지 추적).

## 결정 상태 어휘

- **채택**: 현재 프로덕션 의존성으로 사용 중이거나 사용하기로 확정.
- **부분채택**: 일부 기능만 사용/opt-in, 나머지는 미사용.
- **보류(watch)**: 지금은 안 쓰지만 조건 충족 시 재검토. 재검토 트리거를 반드시 명시.
- **기각(kill)**: 명시적으로 안 쓴다. 기각 사유 + 재검토 조건 명시.
