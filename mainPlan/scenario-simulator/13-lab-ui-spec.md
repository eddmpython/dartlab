# 13. 시뮬레이터 랩 UI 스펙 : 제품 지형 판정 + 시각·모션·스택 (R6 정본)

상태: v1.0 (2026-07-05 전문 리서치 2건 종합: 금융 시뮬레이터 제품 전수 서베이 + 과정 가시화
패러다임·렌더링 기술 조사. 12 §7 의 시각·기술 상세를 본 문서가 담당)

## 1. 제품 지형 판정 (풀 비전 실존 여부)

비전 5축: V1 과정이 보이는 캐스케이드(경제→산업→관계→판독→결정보드) · V2 인터랙티브 시나리오
편집+고품질 재렌더 · V3 전 숫자 근거링크 · V4 결정 diff 의 인과 설명 · V5 미래 타임라인 재생.

**판정: 5축을 모두 가진 제품은 존재하지 않는다.** 각 축의 최고 실현체가 전부 다른 업계에 흩어져
있고 교집합은 공집합, 한국 시장은 근사치조차 없다 (전방향 시나리오 캐스케이드 시뮬레이터 부재).

| 축 | 최고 실현체 (점수/10) | 빌릴 것 |
|---|---|---|
| V1 과정 지켜보기 | Machinations.io (6.5, 게임 경제) | 토큰이 엣지를 따라 흐르는 실행 애니메이션 + 3단 재생(step/play/batch) + 노드 라이브 차트 바인딩 |
| V2 편집→재렌더 | En-ROADS (6.0, 기후) | 슬라이더 패널 + 전 화면 연동 재계산 + 슬라이더별 가정 근거 문서 링크 + 시나리오 공유 URL |
| 관계 그래프 what-if | Reflexivity (5.5) · Palantir Vertex (5.0) | 주식 지식그래프 위 what-if (탐색용에 그침) · 시나리오 = 그래프 위 1급 객체 + 모델 출력→입력 자동 체이닝 |
| V4 diff 설명 | Runway (5.0) · Pigment (4.0, FP&A) | 드라이버 자동 설명문·변동 자동 하이라이트 · waterfall/tornado 로 시나리오 간 diff 드라이버별 분해 |
| V3 근거링크 | Fintool/AlphaSense (검색 전용) | 모든 숫자 클릭 → 원문 인용. 시뮬레이터에 이걸 단 제품은 없음 |
| V5 재생 | TradingView Bar Replay (4.0, 과거 전용) | 재생/배속/한 스텝 + **미래 숨김 규율** (플레이헤드 이후 데이터 물리적 숨김) |
| 기관 시나리오 | Moody's Scenario Studio (4.0) · Bloomberg MAC3 | 상류(경제 모델 전파) 레이어 설계 참고. 과정 가시성·현란함은 전무 |

남은 갭 = 우리 자리: ① 주식 결정(top10)이 캐스케이드의 종착 노드인 제품 없음 ② 시뮬레이션
안에 공시 원문 근거링크 없음 ③ "가정 X 가 판독 Y 를 뒤집어 종목 A 가 빠졌다" 3단 인과 추적
없음 ④ 시뮬레이션된 미래의 재생 없음 ⑤ 한국어 시장 완전 공백. 보조 차용: Guesstimate 셀 안
분포 히스토그램 · Simply Wall St 포크 가능한 내러티브 · TradingAgents Bull/Bear 토론 구조 노출.

## 2. "위키를 써 내려가는 것을 지켜본다" 의 정체 = 이중 표현

운영자 이미지의 실체는 **그래프(공간) + 스트리밍 저널(서사)** 이다 (Perplexity/OpenAI Deep
Research 진행 패널). DAG 캔버스가 번져가는 옆에 저널 패널이 "지금 무엇을 읽고 무엇을 도출했는지"
를 판독 문장 + 근거 ref 로 한 줄씩 스트리밍한다. 완성 전부터 핵심 발견이 떠오른다. 그래프만
있으면 기계 같고 저널만 있으면 챗봇 같다. 둘의 동기(저널 줄 클릭 = 해당 노드 포커스)가 핵심.

## 3. 실행 모델 = ComfyUI 패턴 (이벤트 스트림 구동)

엔진이 `executing(nodeId) / progress(nodeId, k, N) / executed(nodeId, output)` 이벤트 스트림을
내보내고 UI 는 이 스트림만으로 애니메이션을 구동한다 (폴링 금지. 로컬 서버 = SSE, pyodide =
Worker+Comlink). 실행 중 노드 halo + 내부 진행바, 캐시된(안 더러워진) 노드는 흐리게 스킵 표시,
노드 안 미니 프리뷰(스파크라인·판독 한 줄)가 라이브로 채워짐. 결정론 DAG + dirty 전파와 1:1.
여기에 결합: marimo 식 **stale 예고**(재계산 전에 영향권을 먼저 amber 로 물들여 "무엇이 바뀔지"
예고) + LangGraph Studio 식 **타임트래블 포크**(이력의 임의 노드로 되감아 가정 수정 → 그
지점에서 시나리오 분기 = 별도 폼이 아니라 "과거로 돌아가 바꿔보기").

## 4. 렌더링 스택 (SvelteKit, 기존 자산 우선)

- **주력: @xyflow/svelte (Svelte Flow 1.x)** + elkjs 레이아웃(Web Worker, 토폴로지 캐시) +
  **입자·리플 전용 canvas 오버레이 1장** (뷰포트 transform 동기, rAF 루프 1개) + svelte/motion
  Tween·Spring + animate:flip + crossfade. Svelte Flow 는 runes 재작성이라 노드 = Svelte
  컴포넌트: MiniFinChart·스파크라인을 노드 안에 그대로 박는다. 쾌적선 = 리치 노드 수백 개
  ($state.raw 필수) = 회사 단위 연쇄 뷰에 부합.
- 엣지 애니메이션은 CSS dasharray 대량 적용 금지 (검증된 병목). canvas 오버레이가 Machinations
  식 토큰 플로 + TripsLayer 식 페이딩 트레일 담당 (deck.gl 자체는 불필요).
- **매크로 뷰(전 상장사·수천 노드)는 기보유 cosmos GPU 로 분리** (`EcosystemMap.svelte` 가
  이미 회사 x 산업 x 공급 엣지를 cosmos 로 렌더 중 = 관계망 캔버스의 기존 자산. 랩의 편집
  가능 뷰는 Svelte Flow, 장관용 유니버스 뷰는 cosmos 확장).
- **3D 기각**: 라벨·숫자·diff 가 본체인 분석 화면에서 3D 는 가림·불안정 위치·카메라 비용으로
  신뢰를 판다. 깊이감은 2D 안에서 (레이어 elevation 그림자·비포커스 blur/dim·줌 시맨틱 디테일:
  멀면 히트맵 점, 가까우면 카드). 현란함은 "재계산 극장" 순간에 몰아주고 크롬은 절제 (Linear/
  Kowalski 원칙: 매일 쓰는 도구는 무애니메이션이 기본, 언제 안 움직일지가 격을 만든다).

## 5. 모션 스펙 (타이밍 계약)

**시퀀스 A: 가정 편집 → 리플 → 보드 diff**
1. 가정 = Tangle 식 스크러버블 숫자 (드래그 중 프리뷰, 놓으면 커밋). 커밋 = 노드 펄스 180ms.
2. stale 예고: 하류 BFS 영향권을 깊이당 30ms 스태거로 amber 파도 (전체 500ms 내). 비영향
   서브그래프 opacity 0.6 감광.
3. 재계산 리플 (이벤트 구동): executing = halo (최소 200ms) → executed = 값 카운트업 400ms
   (tabular-nums) + 델타 칩(+3.2%p) 부상 + green flash 300ms + 부모 엣지 입자 2~3개 발사
   (250ms 주행, 색 = 델타 부호). 페이싱: 계산이 더 빨라도 깊이 레벨당 최소 80ms (인과가 읽히는
   속도), 500 노드 상한 ~2.5s. 동시에 저널 패널 스트리밍 (§2).
4. 보드 diff: 행 재정렬 animate:flip 500ms + 변경 셀 배경 워시 1.2s 감쇠 + 순위 화살표.
   **안 변한 행은 절대 안 움직임.** A/B 는 crossfade 로 같은 기업 카드가 컬럼 사이 모프 +
   Pigment 식 waterfall 로 "무엇이 diff 를 만들었나" 드라이버 분해 + 책임 가정 역추적 문장.
5. 종결: 상태바 실측 한 줄 ("41개 노드 재계산 · 340ms") = 연출의 신뢰를 실제 숫자로 봉인.
6. 토폴로지 변경 (시나리오 추가/제거): elkjs 재레이아웃 → 기존 노드 FLIP 글라이드 500ms,
   제거 scale+fade 200ms, 신규 서브트리 엣지 draw-in 후 노드 pop-in 스태거.

**시퀀스 B: 타임라인 재생 (미래 전개)**
- 트랜스포트: 재생/일시정지 · 배속 0.5/1/2/4x · **step 모드(한 틱씩)** · 이벤트 틱 박힌 스크러버
  (Machinations 3단 재생 + TradingView 컨트롤 결합). batch(몬테카를로 N회 요약) 는 fan 뷰.
- 단일 `currentTime` 상태가 유일한 시계, 전 요소 $derived 보간. 재생 중 차트는 플레이헤드까지
  스스로 그려지고 엣지 입자 유량 = 시점 t 영향 크기, 최근 변화 노드는 페이딩 트레일.
- **미래 숨김 규율**: 플레이헤드 이후 데이터는 물리적으로 숨김 (TradingView Bar Replay).
- 스크럽 = 즉답 (값 점프, 무애니메이션. 사용자 주도 조작은 즉시), 재생 = 애니메이션. 이 구분 엄수.
- A/B 동시 재생: 동기 플레이헤드 2개 + 곡선 사이 diff 밴드가 시간 전진과 함께 채워짐.

성능 계약: rAF 루프 1개 · 입자는 canvas 오버레이 전담 · 노드 배열 $state.raw · 레이아웃/엔진
worker 분리. 500 노드 + 상시 입자에서 60fps 방어.

## 6. 판독 노드의 내용 표현 (차용 종합)

- 판독 노드 인라인: 방향·강도 + Guesstimate 식 미니 분포(불확실성) + 성적표 인용 칩(수축
  추정치·표본·미검증 라벨) + 근거 ref 클릭 → 공시 원문 (Fintool 표준. 시뮬레이터에 이걸 단
  제품이 없다 = 우리 V3 차별점).
- 판독 충돌 노드는 Bull/Bear 구조 노출 (TradingAgents): 반대 방향 표면들의 근거를 대치로 표시.
- 시나리오 = 1급 객체 (Palantir Vertex): 저장/포크/비교가 원본 오염 없이, En-ROADS 식 공유 URL
  직렬화, Simply Wall St 식 "가정 붙은 내러티브 포크".

## 7. 착수 (R6 세부. 12 §7 승계)

R6-0 pyodide 코어 스파이크 → R6-1 이벤트 스트림 프로토콜 (엔진 쪽, R1 골격에 미리 반영:
opine/cascade 가 노드 단위 yield) → R6-2 Svelte Flow 캔버스 + 저널 패널 (읽기 전용, 봉인 블록
재생) → R6-3 가정 패널 + dirty 리플 (랩 v0) → R6-4 타임라인 재생 + A/B diff → R6-5 매크로
cosmos 뷰 연결. 전 단계 로컬 프리뷰 격리, push 는 운영자 눈검수 승인 후.
