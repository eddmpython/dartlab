> v1.0 (2026-07-07). 운영자 5요건 + "과거는 바텀업 귀속, 미래는 탑다운 분해" 구도의 구현 기획.

> 전개의 깊이는 측정된 법칙의 두께에 비례해야 한다. 검증은 재예보(hindcast)가 한다.

## §0. 한 줄 요지

**지금 지을 것은 보행자(walk)가 아니라 보행 면허 시험장(hindcast)이다.** 걸음수별 오차 곡선이
숫자로 존재하게 만들고, 그 곡선이 어떤 채널을 몇 걸음까지 걸어도 되는지(h*)를 정한다. 곡선 전에
짓는 모든 보행 구조물은 격자처럼 강등될 운명이다 (격자 3렌즈 판정의 교훈 직접 적용).

## §2. 확정 개념 (패널 5렌즈 합의)

- **하나의 지도**: 바텀업 귀속(과거)과 탑다운 분해(미래)는 별도 모델이 아니라 같은 측정 객체를
  양방향 소비한다. 객체 = 합산 구조 S(종목→159업종→시장, 미분류 폐합) + PIT 지연 가중 w(t-1
  시총/매출) + 로딩 L(베타·인증 탄성, 단위 선언 필수).
- **과거 = shift-share 항등 분해**: r_it = 매크로항 + 산업항 + 고유항. 합 = 실현이 기계 검증되는
  회계 분해(인과 아님, 라벨 강제). 고유항의 시총가중 합 = granular 잔차 Γ (Gabaix 2011: 대기업
  개별충격이 거시를 만든다. 삼성 집중 KR 에서 실측 가치 최대). 층별 R² = **법칙 두께의 실측치**.
- **미래 = 같은 로딩의 전치 소비**: 충격 → 인증 탄성만 업종 착지 → conditionalE → 베타 반응.
  귀속에서 두께가 안 잰 채널은 전개에서 기권 (바텀업 R²·인증쌍 = 탑다운 통행증).
- **재예보 2팔**: (a) 실측 매크로 경로 주입 = 회사층 법칙 격리 채점 (b) 부채꼴 = 스텝별
  coverage/CRPS. 걸음수별 skill(h) 곡선에서 carry 벤치마크를 못 이기는 첫 걸음 = 그 채널의
  전개 한계 h*. **h* 가 "전개 깊이는 법칙 두께에 비례"의 기계화다.**
- 세계 개념 차용: 계층 예측 조정(Hyndman·MinT = v2), Gabaix granular origins, shift-share(Bartik),
  기상 reforecast + lead-time skill curve(Hamill/NOAA), XVA EE/PFE 스텝 곡선, CCAR 고정경로 주입,
  Kilian 수요/공급 분해(do-의미론 한계 라벨), 생존분석 절단 관측, Giacomini-White 조건부 검정.

  (d) 연도별 업종맵 매칭률 곡선 (지도 생존편향 정량화)
  (e) 직교화 순서 민감도 델타 + 가중 t-1 look-ahead 카나리아

## §6. 단계 2: hindcast.py (주 2, 유일 신규 본진 모듈)

선결재: **multi-horizon 라벨 빌더** (weeklyLabels 는 5거래일 하드코딩. fwd k주 라벨 + 중첩 규율).

- **팔 (a) actualPath**: origin(2019~2026, 간격 >= 지평 8주, 사전등록 ~45개)마다 법칙을 origin
  이전 데이터로 **재발굴**(베타·방향사전·탄성. 순환 차단)하고 실측 매크로 경로를 주입 → 회사층
  IC(h) 곡선 + Newey-West t + h*_firm. 산출 스키마에 arm 라벨 필수 = "조건부(매크로 실경로 가정)
  채점이지 트랙레코드 아님" 영구 명시.
- **팔 (b) fan**: lattice per-step marginals(소형 확장) → h=1..8 각각 ExpectationSpec
  (issuedLive=False) 봉인 → coverage80/50(h)·CRPS(h)/carry 곡선 + h*_env.
- **net 병기**: 걸음별 채점에 비용바닥(~1%/주 실측) 차감 열 동반. 다걸음 회전의 가치는 net 에서만.
- **판정 규칙 사전 봉인** (h* 사후 이동 금지, 코드 해시로): 전 채널 x 전 지평 곡선 통봉인(선별
  인용 금지), 개별 셀 주장 금지(곡선 추세만), 어떤 채널도 carry 를 못 이기면 **"다걸음 전개 기각·
  현 1스텝 유지" 박제가 정직한 산출** (VAR 기각 동형. 기각도 가치다).
- 죽은 회사: origin 시점 유니버스 + 절단 라벨 포함 (단계 0-2 의 deathLabels 소비).
