# 06. 엔진 판독·가정 sweep : 시뮬레이터의 "현재" 축 (검증 루프를 채우는 조각)

상태: v1.0 (2026-07-05 운영자 합의 "여기에 태우자". 토론 이력·P0 실측 = `../weekly-uplift-shortlist/05-progress-ledger.md`)
위치: 본 문서군의 시간축에서 **현재** 를 담당한다. 과거 = expectation 원장 채점(expectation-grid, 라이브 가동), 미래 = Play fan(05). 00 §8b 의 conditional-signature 판정("검증 루프 미완이라 시그니처가 될 설계")에서 비어 있다고 지목된 **그 검증 루프의 대규모 실장**이 본 축이다.

## 1. 본질 (합의 원문)

한곳(L2.5 `simulate`)에서 모든 하위 엔진을 호출해 데이터를 받고, 출처별·엔진 성격별로 투영해
한곳에서 의견화(판독)한다. 전량을 발행 시점에 봉인하고 5거래일 뒤 채점해 성적을 누적한다.
그 의견 위에 모든 방향과 if(이 방향이라면·이런 상황이라면)의 수백수천 가정을 돌린다.
수용된 규율 1건(다중검정): 종목 선정은 최고 성적 가정이 아니라 **가정 강건성(median)** 으로,
가정 자체도 판독처럼 봉인·채점되어 살아남는 가정이 가중을 얻는다. 최적은 사전 탐색의 선언이
아니라 원장의 사후 증명이다.

## 2. 판독 계약 (Reading)

```python
@dataclass(frozen=True)
class Reading:
    stockCode: str; market: str            # KR 전상장사 / US EDGAR (시장 내 완결, 혼합 순위 금지)
    surface: str                           # 표면 id (전수 레지스트리 키: "scan.orders"·"quant.momentum"·
                                           #  "allFilings.유상증자"·"panel.accrualsDelta" ...)
    asOf: str; horizon: int                # PIT 기준일 · 거래일 지평 (v0=5, 표면별 자연 지평 다중 가능)
    direction: int; score: float | None    # +1/-1/0(중립·기권) · 강도
    abstainReason: str | None              # 기권 1급 출력 (0 대체 금지, 기권률도 채점 대상)
    refs: dict                             # 근거 dateRef/datasetRef (출처는 여기 자연 기록)
```

모든 회사가 매주 표면마다 "판독/중립/기권" 셋 중 하나로 기록된다 (silent 누락 0, 전상장사 규약).

## 4. 주간 루프 : 판독 → 봉인 → 채점 (기존 원장 자산 재사용)

- 발행·봉인: `expectationCycle` 확장 `issueReadings` (issueMacro 동형. 유일 writer·append-only·
  issuedLive 규약 그대로). 선정 이전 전량 봉인 = selection bias 구조적 차단.
- 채점 타깃: 5거래일 후 **사이즈 버킷 중립 초과**(주별 시장 내 시총 버킷 평균 대비, DGTW 계열)
  + 원시 시장평균 초과 병기. 스타일 편승(소형주 랠리 해)을 표면 실력으로 오인하는 것을 차단하고
  횡단면 상관을 원천에서 줄인다. 재료는 gov/prices MKTCAP 직독(실측 확인). 섹터 버킷은 소스
  확보 후 추가.
- 통계의 원자 단위 = 주(週): 표면 통계는 전부 "주별 횡단면 집계 1값 → 시계열 Newey-West t"
  (Fama-MacBeth 계열·calendar-time)로만 계산. per-event t 금지 (이벤트가 주 안에서 군집·상관해
  표본수가 부풀던 문제의 구조적 해결. KP 횡단상관 보정 BMP 를 교차검으로만 병용).
- 비용 바닥(net-of-cost): 발행 시점에 종목별 비용 바닥을 봉인. 고저가 스프레드 추정
  (Corwin-Schultz·Abdi-Ranaldo, gov/prices 고저가 직독) + 1틱 하한 + **거래일자 기준 세율표**
  (매도세: 2025 KOSPI 0.15%·KOSDAQ 0.15% → 2026-01-01부터 양시장 0.20%) + 유관기관비용
  0.0036% x2. gross / floor / net 3열 병기, 표면 통과 판정은 net 기준. 실측(2026-07-05): KR 왕복
  유효 스프레드 중앙 0.68% → 주간 전량 회전의 비용 바닥 약 0.9~1.0%/주. +0.5%/주급 총초과는
  비용에 전멸하고, 회피(red-flag) 표면은 비용 0 이라 가치가 그대로 성립한다.
- 성적표: 표면 x 시장 x 산업 x 레짐 x 지평. 수축(표면 ← 상관 클러스터 ← 전체) + 표본 게이트
  미달 "미검증" 라벨 = **03 §4.4 G16(coverage·PIT·skill 게이트) 정합** (새 게이트 발명 0).
  독립성 묶음은 분류표가 아니라 채점 데이터의 상관이 정한다.
- 표면 승격 2단 깔때기: **발굴** = 주단위 t 에 BH/BHY FDR(q 5~10%) + 운영 상수 **t>3.0**
  (factor zoo·Harvey-Liu-Zhu. 미달 표면은 "동물원과 구분 불가" 라벨로 등재 유지). **인증** =
  전수 스캔 우주에 Hansen SPA + Romano-Wolf stepdown (정상성 부트스트랩을 주 단위로 재표집해
  타입 간 상관 보존. arch 미설치 확인, numpy 자급 구현). 신규 표면의 기여는 기존 표면 앙상블에
  residualize 한 뒤 측정 (Numerai MMC 동형: 수백 표면이 소수 아이디어의 중복으로 이중 계산되는
  것 차단).
- 09 §10 fatal② "forward-test write 끝단" 을 본 루프가 대규모로 채운다 (주간 전종목 x 전표면).

## 5. 가정 sweep : 두 층, 한 원장

| 층 | 내용 | 기존 자산과의 정합 |
|---|---|---|
| 상황 가정 | "이 방향이라면·이런 상황이라면": 레짐 상태·명명 프리셋 (baseline/adverse/china_slowdown/rate_hike/semiconductor_down) | 신설 0: `getPresetScenarios("KR")` 1급 소비, `provenance=preset:{scenarioId}` (02 §명명 프리셋 A1 규약 그대로) |
| 결합 가정 | 표면 가중 스킴·게이트 강도·유동성 조건·합의 임계·지평 | 신규 경량 row. AssumptionLedgerRow(02 §2.5, 코드 0건 설계)의 규율을 첫 적용: 단위·기간 필수, source·status·반증조건(=사전등록 protocol) 필수 |

- 격자 수백~수천 벌은 판독 행렬(주 1회 계산) 위의 재조합이라 전부 벡터화 (P0 실측: 17년
  전종목 replay 4초 → 1,000벌 x 17년 = 분 단위).
- 선정 = 강건성(대다수 가정에서 반복 상위, median). 최고 성적 가정 인용 금지 (다중검정).
- sweep 마다 자동 산출·병기 4종: **PBO**(CSCV S=16, configs x weeks 행렬에서 직접 계산),
  **OOS 열화 기울기**, **P(OOS 손실)**, **가정 중앙값**. 실측(2026-07-05, 200벌 x 543주, 12,870
  조합 0.6초): PBO 0.015 인데 열화 기울기 **-0.95** = 선정 절차는 구조적으로 나은 config 를
  고르지만(순위 지속) IS 최고 성적의 크기는 완전 평균회귀. config 상관 클러스터 축약(200→45)
  후에도 동일. 순위(PBO)와 크기(기울기)를 반드시 함께 보고, 기대 OOS 는 중앙값으로 말한다.
- 발간 승격 가정은 **DSR**(Deflated Sharpe, 유효 N = config 상관 클러스터 수, N_eff 범위 병기)
  0.95 이상만. 봉인 원장이 시도 횟수 N 을 정확히 기록하므로 DSR 이 학계와 달리 정직하게 계산
  가능하다는 것 자체가 자산.
- 상황 가정(조건부)의 채점: **레짐 분류기**(결정론 코드·공개 데이터·버전 해시)를 사전 봉인하고,
  조건 태그 판독은 실현 레짐이 일치한 주에만 채점 (불일치 주는 "조건 미실현·미채점" + airtime
  분모 기록: 희귀 조건 뒤에 숨어 무패 기록을 만드는 것 차단). 레짐별 실력 차 주장은
  Giacomini-White 조건부 예측력 검정 통과분만. 이것이 "조건부 시뮬은 원리적으로 채점 불가"
  한계의 부분 해결: 실현된 조건은 채점되고, 미실현 조건은 탐색 도구로 남는다. 분류기 변경 =
  새 시리즈 (소급 재태깅 금지).
- 가정 벌도 매주 봉인·채점. 과거 sweep 은 bootstrap(issuedLive=False 영구 표기), 권위는 라이브만.
- 격자 범위 변경은 분기 사전등록으로만.

## 5b. 시뮬 종류의 확장 계약 (고정 목록 금지)

경제(macro BVAR fan·명명 프리셋)·재무(proforma 캐스케이드)·가격(conformal·Play path)·퀀트(판독
+가정 sweep)는 **첫 등재 4건이지 고정 분류가 아니다** (운영자 예시, 2026-07-05). 시뮬 종류도
표면과 같은 레지스트리이며, 새 시뮬은 다음 4계약을 채우면 등재된다:

1. **원천 계보**: 소비하는 데이터·공개 verb (원천의 연장선 원칙, refs 기록)
2. **가정 축**: 이 시뮬의 if 들을 AssumptionLedgerRow 계약으로 선언
3. **산출 계약**: 기본형 = **원천 동형 시계열 연장** (운영자 정의, 2026-07-05). 출력은 원천과
   같은 스키마·같은 시간 격자로 원천 시계열 뒤에 이어 붙는 미래 구간이다 (월별 매크로 → 미래
   월들, 분기 panel → 미래 분기 행, 일별 가격 → 미래 path). 연장 행에는 simulated 라벨
   (scenarioId·vintage·provenance) 필수 = 실측과 절대 분리. 효과: 과거를 소비하던 차트·엔진이
   연장 구간을 재배선 0 으로 소비, 실제값 도착 시 같은 격자에서 1:1 채점. 기존 실장 2곳
   (issueMacro 월별 분위 봉인·proforma 분기 연장)의 일반화. 횡단면 판독처럼 연장이 아닌
   산출은 예외형으로 명시 선언. 연장 구간의 불확실성은 **conformal 밴드**로 함께 낸다:
   횡단면 분할 conformal(주별 전종목 점수 풀 + 종목 변동성 표준화, Mondrian 버킷별) x 시간축
   **ACI**(Adaptive Conformal Inference: 지난 주 실측 커버리지로 유효 α 를 피드백 제어.
   분포 이동과 무관하게 장기 커버리지가 선언값에 수렴함이 증명된 계열). 효과: "80% 밴드"
   선언 자체가 매주 채점 가능한 약속이 된다 (적중 여부 + Winkler 구간 점수 병기). 주장 규율:
   장기 수렴만 보장, 개별 주 커버리지 주장 금지·버킷별 커버리지 병기(전체 80% 가 소형주 60%
   를 숨기는 것 차단). 정직한 밴드는 넓다: 가치는 좁음이 아니라 선언 커버리지가 실측과
   일치함의 증명에 있다
4. **채점 규칙**: 실제값 도착 시 무엇으로 채점되는가 (지평·실제값 소스). 채점 불가 탐색용
   시뮬은 등재 가능하되 영구 "미채점" 라벨

불변은 이 4계약 + 원장(봉인·채점·도태는 성적)뿐. 종류 추가에 엔진 재설계 0. 시간축(과거 채점·
현재 판독·미래 fan)과 시뮬 종류 축은 직교한다 (예: 재무 시뮬은 과거 replay 로 채점되고 미래
fan 으로 펼쳐진다).

## 5c. 일 단위 계산 계약 (저빈도 원천의 일별화. 2026-07-05 연구·실측 반영)

모든 계산의 기저 격자는 일(日)이다. 분기 재무 같은 저빈도 원천을 일별 격자에 올리는 방법은
계층별로 딱 하나씩만 허용한다 (혼용 금지):

1. **피처 계층 (판독 입력) = PIT 계단 + 이벤트타임만.** 유일하게 구조적으로 look-ahead 가
   불가능한 두 형태다:
   - PIT 계단 carry-forward: as-of join (`rcept_dt` 발효, 장후 접수는 익영업일). 값과 함께
     **staleness age**(경과 거래일)를 쌍으로 공급. TTM 은 공시 이벤트마다 재계산 (KR Q4 =
     사업보고서 연간 - 3Q 누적, 유도 시점 = 사업보고서 rcept_dt). 정정공시는 최초 보고값
     vintage 유지 (최신본 덮어쓰기 금지).
   - 이벤트타임 재정박: 피처 = (서프라이즈 크기, τ = 공시 후 경과 거래일) 곡선. SUE 는
     seasonal-random-walk 형(직전 8분기 분포로 표준화)이 기본: 컨센서스가 없어도 **전종목
     계산 가능**해 전상장사 규약과 유일하게 정합. 같은 업종 기공시 peer 의 SUE 는 미공시
     기업의 횡단면 피처 (분기 내 공시 시차 = ragged edge 자체가 정보).
   - 가드 2종 상주: **replay 항등성**(과거 임의 날짜의 피처 재계산 = 봉인본 byte 일치) +
     **look-ahead 카나리아**(어떤 피처든 rcept_dt 이전 날짜에 값이 생기면 테스트 fail).
2. **nowcast 계층 = 시뮬 종류 등재 (§5b 4계약 충족).** 진행 분기의 실적을 일별로 추정하는
   것은 관측이 아니라 시뮬이다: `simulated:nowcast` + 모델버전 + as-of 로 매일 봉인. v0 =
   업종 풀링 U-MIDAS/sg-LASSO 패널 (모수 적고 misspec 강건), v1 = 혼합빈도 Kalman (일별
   run-rate 잠재상태 + 분기값을 "공시일에만 관측되는 결측 시계열"로. filter 는 one-sided 라
   PIT 안전, smoother 백필 금지·파라미터는 expanding window). 지표: KR 10/20일 수출·산업
   생산·peer SUE·일별 가격/거래량. 채점 = rcept_dt 도착 시 그 분기의 봉인된 전 일별 nowcast
   일괄 채점, 공시까지 남은 일수별 skill curve, 벤치마크 2종(SRW·최신 컨센) 대비 상대 RMSE.
   벤치마크 미달 구간은 자동 강등.
3. **표시 계층 = 통계 분해 (Chow-Lin·Denton-Cholette), 피처 합류 영구 금지.** 표준형은
   two-sided(새 분기 도착 시 과거 일별 값 전부 개정)라 그 자체가 look-ahead. 과거 완결 구간
   차트·도시에르 전용 `simulated:disaggregated` 라벨, 진행 분기 꼬리는 2번 nowcast 를 그대로
   노출(이중 시뮬 방지). vintage 개정 폭을 정직 지표로 병기.
4. **전면 금지**: 분기 사이 선형/스플라인 보간을 피처로 (정의상 look-ahead) · two-sided
   출력 백필 · 전체 표본 추정 파라미터의 과거 재적용.

**일별 발행의 실측 근거 (`eventDailyDecay.py`, 2026-07-05)**: 강한 음(-) 표면의 드리프트는
빨리 죽지 않고 10일+ 누적 (분할조정 후 전환청구권행사 D+1 -1.0% → D+10 -5.5%, 조회공시
-4.2%, 최대주주변경 -2.5%). D+1 진입은 주말 배치(평균 D+2.5 진입) 대비 잔여 드리프트를 약

## 7b. 시그니처 메커니즘 스택 (2026-07-05 연구 반영: 무엇이 이것을 dartlab 의 시그니처로 만드는가)

시그니처의 원천은 "잘 맞춘다"가 아니다 (M6 실증: 정확도와 투자성과는 사실상 무상관, 대부분이
단순 벤치마크도 못 이김. 적중 주장으로는 신뢰도 차별화도 안 된다). 시그니처는 세 속성의 결합이며,
셋 다 지금 자산으로 구현 가능함이 실측·검증됐다:

1. **조작 불가능한 공개 봉인 (재계산 가능성 원칙)**: 주 1블록 해시체인
   `{판독 전량, 비용 바닥, 레짐 태그, ACI α, 결합 가중, 코드 버전 해시, prevHash}` 를 발행 즉시
   공개하고 외부 앵커(OpenTimestamps: 블록 해시를 비트코인 블록에 무료 앵커, 운영자 독립
   타임스탬프)로 고정한다. 채점은 다음 블록에서 "직전 블록 + 공개 가격"의 순수함수로만 계산
   → 외부인이 원장 replay 로 전 수치를 byte-for-byte 재검산 가능. 선택적 앵커 금지 (빈 주도
   증거다). Numerai TC 폐기의 교훈이 근거: 참여자가 로컬 재계산 못 하는 지표는 신뢰를 파괴한다.
   채점 규칙은 단순·공표·결정론이어야 한다.
2. **파라미터 프리 결합 (커브핏 0 의 증명)**: 표면 결합 가중은 백테스트 적합이 아니라
   **AdaHedge**(전문가 조언 온라인 학습: 표면 = 전문가, 주간 손실로 곱셈 가중 갱신. 학습률까지
   과거 손실의 결정론 함수라 조정 나사 0). 보장: 어떤 분포 가정 없이 사후 최강 표면 대비 누적
   후회 O(√(T ln N)), 주간 지연 피드백은 √2 배 이내. 후회 곡선 자체가 원장의 순수함수라 매주
   공개 채점된다. 손실 함수(적정 점수 Brier / net 재무 손실 클립)는 사전 봉인, 표면 추가·은퇴는
   sleeping-experts 규약 선언으로만 (생존편향 잠입 차단). 주장 규율: 상대 보장(최강 표면 추종)
   이지 수익 보장이 아님을 명기.
3. **검증 깔때기의 전 층 실장**: 채점 타깃 중립화(§4) → 주 단위 원자(§4) → FDR 발굴 + SPA 인증
   (§4) → sweep PBO·DSR(§5) → 레짐 조건부 GW(§5) → net-of-cost(§4) → conformal 커버리지 약속
   (§5b). 이 스택 전체가 봉인 원장 위에서 자동 재계산되는 시스템은 공개 생태계에 전례가 없다
   (Numerai 는 비공개 데이터·폐쇄 채점, M6 는 100자산 12라운드, 학계는 봉인 없는 사후 백테스트).
   전상장사 x 주간 x 공개 봉인 x 이론 보장 결합이 교집합이 되는 지점이 dartlab 의 자리다.

- 지표 버전 관리: 채점·중립화·비용·레짐 코드는 버전 해시로 봉인, 변경은 새 시리즈. **봉인 이력
  소급 재채점 금지** (Numerai 의 MMC→TC→MMC 지표 교체 파동이 반면교사).
- 언어 규율 추가: 후회 보장·커버리지 보장은 "수익 보장" 으로 번역 금지 (never-claim 상속).
