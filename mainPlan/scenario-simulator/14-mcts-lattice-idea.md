# 14. 아이디어 노트 : MCTS형 시나리오 격자 + 신경망식 결정 GUI (기록, 미착수)

상태: v0.1 아이디어 (2026-07-06 운영자 토론 "수천수만 가정 확대·가지치기·끝까지" + "신경망식 GUI 가능한가" + "시그니처 가능성"). 성격: **기록·토론 산물이지 빌드 승인 아님.** 착수는 _attempts 개념검증 게이트 경유(§5). GUI 는 운영자 명시 트리거("지어") 전까지 절대 미착수, 본 문서는 데이터 계약·아이디어만 박제.

## 1. 이름과 프레임 (토론 결론)

- 운영자가 묘사한 것("미래 가정을 수천수만으로 확대, 계산, 가지치기하며 끝까지")의 기술명 = **MCTS(Monte Carlo Tree Search)** 계열. 가지치기 개별 이름: 알파-베타 가지치기(게임트리)·분기한정법(branch-and-bound)·시나리오 축약(scenario reduction)·UCB 선택(MCTS 심장). 물리 은유 = 파인만 경로합, 기상 은유 = 앙상블 예보. "시나리오 시뮬레이터"는 우산이고 MCTS 는 그 안의 구체 알고리즘.
- **정직 프레임 (핵심 규율)**: 영화(닥터 스트레인지 1,400만 미래 중 이기는 하나)는 판타지다. 주식에서 "이기는 경로 하나"를 찾으면 그게 곧 과최적화(우리가 certify·PBO·DSR 을 지은 이유). 정직한 정의 = **예언기가 아니라 분포·강건성·생존 기계**: ① 미래 분포(부채꼴) ② 대다수 가지에서 살아남는 강건 결정 ③ 최악 가지 생존(스트레스). 알파고는 규칙 확정 게임이라 MCTS 가 예언이 되고, 주식은 절반이 노이즈라 분포 기계로만 진실.

## 3. 구현 청사진 A~D (설계 스케치, 착수 시 상세화)

핵심 관건 = **트리 폭발 억제**. 순진 트리는 3^(팩터x깊이)로 폭발(깊이 4 = 53만 잎). 답 = **재결합 격자(recombining lattice, 금융 삼항트리 정통)**: "상승 후 하락 = 하락 후 상승" 상태 병합으로 잎 O(T²) 억제 + 결정론.

- **A. 매크로 동역학 (한 마디 전진 엔진, 신규 소형)**: VAR(1) `X_t = c + A·X_{t-1} + ε(Σ)` 를 역사 주간 변화로 적합. 시간 전파(유가→차기 금리→환율) 담당. 정직 예상: 매크로 주간 변화는 준랜덤워크라 A 가 약할 것. A≈0 이면 격자는 RW+Σ(이미 보유)로 가는 것 자체가 개념확립 결과.
- **B. 재결합 격자 성장 + 가지치기 (신규, 심장)**: 마디마다 팩터별 {-1σ, 0, +1σ} 삼항 분기 → 같은 누적상태 병합 → 저확률 상태 beam 컷(~1000). 상태 = {t, 팩터수준, 경로확률, 이력}.
- **C. 마디별 결정 (기존 재사용)**: 각 격자 상태에서 `adjustedScores` 벌크 행렬 1방(betas @ 전상태) = Company 루프 0·메모리 안전.
- **D. 집계 = 분포 + 강건성 (신규 소형)**: 잎을 경로확률 가중 → 결과 부채꼴·강건 top-K(고확률 잎 대다수 생존)·최악 5% 경로 생존율. "이기는 미래" 산출 금지(과최적화 차단, §1 프레임 강제).

난관 3: ① 가지치기 규칙이 알고리즘의 전부(beam 폭·병합 기준) ② VAR 약함(출력이 예언 아닌 스트레스인 이유) ③ 끝단 평가를 경로내 수익 최적화로 하면 과최적화 = certify/PBO 규율 격자 상속 필수.

## 4. 시그니처 가능성 판정 (2026-07-06 토론)

- **알고리즘 단독 = commodity.** 격자·VAR·MC 는 교과서고 Aladdin·MSCI·Bloomberg 전부 보유. "우리도 MC 있음"은 입장료지 차별화 아님 (00 §8c commodity 규율, planScore≠시그니처 재판 금지).
- **조합 = dartlab 최강 시그니처 후보.** 공식: **시나리오 격자 x 전상장사 공시 데이터 x 반과최적화 정직 원장**. 근거 ① KR 전상장사+공시 레버(희석 회피 -0.46%/주 무비용)는 기관 도구 사각 ② "수천 미래에서 안 죽는 결정"을 공개 봉인 원장으로 재검산 가능하게 내는 물건은 시장에 없음 ③ 측정 노출 기반(형질 조건화 tGap 3.19 실증) 데이터 깊이는 KR 유일.
- **지위 = 후보이지 시그니처 아님 (conditional-signature 61 유지).** 승격 게이트: ⑴ 라이브 채점 누적(시간, 최대 관문) ⑵ 정밀도 부채 상환(유동성 필터·베타 winsorize·금리 팩터 대체) ⑶ 격자 개념검증 통과. 화려함이 아니라 원장이 증거.

## 5. UI 아이디어 (기록만, 착수 금지 = "지어" 트리거 대기)

신경망식 밈 이미지(층상 발화 그물)가 가리키는 화면이 우리 데이터로 실현 가능함을 실측 완료:

- **데이터 계약 이미 방출**: `scenarioTree.decisionNetwork()` = 노드 3,037(입력3→회사2,874→업종159→결정1)·엣지 8,358 JSON. 노드 activation=발화 강도, 엣지 weight=측정 베타. 표면 엣지 포함 시 3만+.
- **수렴도 실측**: MC 경로 N=50→200 에서 top15 일치 50%→88% 안정화 = "수천 갈래가 결과로 좁혀짐"이 데이터로 성립.
- **화면 상상 (13-lab-ui-spec 연장선)**: ① 신경망 뷰 = 층상 발화 그물(cosmos WebGL, 1만+ 노드 여유). 시나리오 슬라이더를 움직이면 매크로 입력층에서 발화가 퍼지고 결정층으로 수렴하는 애니메이션 ② 격자/부채꼴 뷰 = 시간축 격자가 자라며 가지치기로 소멸하는 경로 + 확률 가중 부채꼴 ③ 상호작용 = 노드 클릭 → 책임 팩터 역추적(entrants/responsible 이미 산출), 가정 편집 → recompute dirty 하류만 재발화(계약 실재).
- **차별점**: 밈의 신경망은 학습 가중치(해석 불가)지만 우리 엣지는 측정 베타(왜 발화했는지 설명 가능). 표현이 아니라 해석가능성이 무기.
- 스택·모션 상세는 13 정본. 본 절은 "격자·신경망 뷰" 컨텐츠 아이디어 추가분만.

## 6. 착수 순서 (승인 시)

1. **A 개념검증** `tests/_attempts/scenarioLattice/` : 주간 VAR(1) 적합 + OOS 1스텝 RMSE vs 랜덤워크. 결과가 격자 설계(드리프트 유무)를 정함. → **✅ 완료, §7.**
2. B 격자+가지치기 프로토타입(_attempts) → 폭발 억제 실측(상태 수 곡선).
3. C·D 배선 + 강건성 출력 → 졸업게이트 후 본진 `simulate/`.
4. GUI 는 전 단계 무관하게 별도 운영자 트리거 대기.

## 7. A 개념검증 실측 (2026-07-06, `varDynamics.py`)

주간 1,380행(2000~2026, train 1,104/OOS 276) 실측:

- **OOS 1스텝 RMSE 비율(VAR/RW): oil 1.013 · fx 1.012 · rate 1.014.** VAR 드리프트가 랜덤워크보다
  전 팩터에서 오히려 나쁨. train 에서 유의한 구조(oil<-rate t+4.4·fx 관성 t+3.1)가 OOS 로 이월 안 됨.
- **판정 (사전 등록 기준 0.97): A 기각. 격자 = RW + Σ(동반이동) 설계 확정.** 시간 전개는 방향 예측이
  아니라 **불확실성 확산 + 동반이동**만 담는다. 방향 정보는 회사 반응(측정 베타)·base 신호 담당.
- 함의: §3-A 는 닫혔고 B(격자+가지치기)는 드리프트 항 없이 더 단순하게 설계된다. 이는 §1 정직
  프레임(예언기 아님)의 데이터 재확인이기도 하다: 매크로 방향은 우리도 못 맞히고, 안 맞혀도 된다.
