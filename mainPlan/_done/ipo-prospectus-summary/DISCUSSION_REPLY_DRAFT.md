## 1. 단건 — 증권신고서 본문 → 6카테고리

```python
from dartlab.providers.dart.securitiesRegistration import classifyIpo, parseIpoProspectus

# IPO 판별 (corp_cls + 첫 괄호 subtype + stock_code 3조건, 사람 라벨 0)
classifyIpo("증권신고서(지분증권)", "E", "", "주식회사 기도산업")
# → {'isIpo': True, 'subtype': '지분증권', 'isSpac': False, 'kind': 'prospectus', ...}

# 본문(dart4.xsd content_raw) → 6카테고리 + 내적 항등식 검증
r = parseIpoProspectus(content)
r["offering"]    # 공모가밴드·모집총액·청약/납입일
r["valuation"]   # 적용 PER·주당평가액·할인율·비교기업
r["financials"]  # 요약재무 3개년
r["allocation"]  # 공모 배정
r["identities"]  # 카테고리별 항등식 통과 여부 (검증 신호)
```

## 설계 핵심 (왜 신뢰 가능한가)

- **기계 판별**: `report_nm 첫 괄호 "지분증권" + corp_cls="E" + 빈 stock_code` 3조건. 6개월 corp_cls=E 826건 중 783건(펀드·채권·유동화)을 자동 배제, 지분증권 43건 오분류 0.
- **구조 앵커링**: 텍스트 변형 정규식 누적이 아니라 dart4.xsd `<TITLE>` 구조로 6섹션 경계 — 발행사 변형에 강건(검증한 발행사 전수 100% 검출).
- **내적 항등식 검증**: 추출값을 원문 자체의 관계식으로 자기검증 — 공모가×주식수=모집총액 / 비교PER×순이익÷주식수=주당평가액 / 주당평가액×(1−할인율)=공모가밴드 / 자산=부채+자본. 발행사 원문의 콤마 오타도 항등식이 검출·복구합니다. 항등식 미통과 값은 `identities`가 명시(에이치엘지노믹스 사례)해, 틀린 값을 맞다고 내놓지 않습니다.
- **고저평가 단정 회피**: 발행사가 *선택한* 비교군 기준 적용 PER·할인율을 좌표로 제시 — 투자판단 단정 대신 비교 위치.
