# 05. Score Rubric: 8차원 능력 채점 기준

루트 README `## 북극성` 점수표의 채점 정본. 점수를 고칠 때는 반드시 이 문서의 근거 줄을 함께 고친다. 근거 줄 없이 숫자만 바뀐 diff는 무효다.

## 1. 채점 규율

1. 축 종합 = 8차원 점수의 산술평균, 0.1 단위 반올림. 차원 점수는 0.5 단위.
2. 점수 근거는 실제로 도는 게이트와 실측 여정뿐이다. 자동으로 실행되지 않는 경로는 구현돼 있어도 세지 않는다. 운영자 수동 실행은 현 상태 서술에 남기되 검증강도 점수로는 세지 않는다.
3. 하향은 즉시(회귀 발견 시 그 자리에서), 상향은 실측 근거 필수. 실측·게이트와 연결되지 않은 차원 점수는 주간 outcome review에서 우선 하향 대상이다.
4. 재판정은 주간 outcome review에서만 한다. 이니셔티브 완료·커밋·배포 자체는 상향 사유가 아니다(제품 행동 실측이 사유다).
5. 10점 = 실사용 환경에서 그 능력의 완결 여정이 반복 검증된 상태. 설계·문서만 있는 축은 차원 무관 0.5~2.5 밴드를 넘지 못한다.

## 2. 차원 정의와 앵커

| 차원 | 0점 | 5점 | 10점 |
|---|---|---|---|
| 근거 | 출처 없는 결과 | 주요 결과에 출처·기준시점 동행 | 모든 결과가 출처·기준시점을 달고 검산 여정이 반복 검증 |
| 커버리지 | 목표 유니버스 미정 | 핵심 유니버스 커버, 경계 결손 명시 | 전 상장사·전 기간·전 표면 무결손 |
| 검증강도 | 자동 게이트 0 | 핵심 경로에 실패 가능한 게이트 상주 | 핵심 행동 전부가 자동 게이트로 단언 |
| 직관성 | 내부 지식 없이 사용 불가 | 문서 한 페이지로 첫 결과 | 배울 것 없이 한 줄로 첫 결과, 이름이 자명 |
| 속도 | 첫 결과까지 수 분 이상·실측 없음 | 캐시 후 수 초, 병목 파악됨 | 첫 결과·재호출 체감 즉시 + 실측치 존재 |
| 효율성 | 중복 빌드·사본·수동 운영 의존 | SSOT 직독, 알려진 낭비 관리 중 | 중복 빌드 0·사본 0·자원 예산 준수 |
| 안정성 | 실패가 침묵하거나 크래시 | 회귀 가드 상주, 실패는 정직 상태로 강등 | 알려진 회귀 0 + 실환경 반복 검증 |
| 혁신성 | 기존 대안의 재구현 | 대안 대비 차별 능력이 실재 | 대안이 못 주는 능력을 실측으로 증명 |
